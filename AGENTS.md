# Instructions for agents

This repository is the Construkted Reality fork of CesiumJS.

Read [FORK.md](FORK.md) before you change anything. It gives the remote names, the branch
layout, the place to commit fork work, and the monthly upgrade procedure.

Two rules are easy to get wrong:

1. Commit fork work to a `feature/<topic>` branch, based on `construkted`. The trunk is
   `construkted`, not `main`. Do not commit to either one directly.
2. Do not edit `CHANGES.md` or `README.md`. Upstream owns them. Use
   `CHANGES-construkted.md` and `FORK.md`.
